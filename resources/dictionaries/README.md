# BPS Publication Audit Dictionaries

Kamus kata resmi untuk modul SpellChecker dan TextLayerNormalizer.

## Berkas
1. `bps_terms.txt`: Nomenklatur, singkatan resmi BPS (KCDA, SLS, Podes, Layouters, dll.), serta nama wilayah dan komoditas baku.
2. `id_ID.dic`: Kosakata baku Bahasa Indonesia untuk laporan statistik BPS (berdasarkan KBBI dan terminologi publikasi).
3. `en_US.dic`: Kosakata Bahasa Inggris resmi untuk terjemahan dwibahasa (bilingual tables, metadata, headings).

## Lisensi & Sumber
- Terminologi BPS mengacu pada Pedoman Publikasi BPS RI.
- Kosakata Indonesia dan Inggris dikurasi dari perbendaharaan terbuka berlisensi MIT / Public Domain.
